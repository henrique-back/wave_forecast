# Rapid Deterministic Wave Prediction Using a Sparse Array of Buoys

**Fisher, A., Thomson, J., Schwendeman, M. (2021).** *Ocean Engineering*, 228, 108871.
DOI: 10.1016/j.oceaneng.2021.108871.

## Summary
Uses a sparse array of drifting SWIFT buoys and a linear inverse (constrained least-squares)
model to reconstruct/forecast phase-resolved instantaneous wave elevation/energy 1-3 wave
periods ahead, validated against simulations and field data.

## Relevance to this manuscript
Medium — buoy-based wave prediction, but a different problem (deterministic phase-resolved
surface reconstruction from a multi-buoy array) and a different method family (linear inverse
model, not ML/transformer, not spectral shape/magnitude forecasting).

## Suggested use
Could support a short "phase-resolved vs. statistical/spectral forecasting" scoping sentence
in the Introduction, clarifying that this manuscript addresses the latter. Not a direct
methodological comparator.
