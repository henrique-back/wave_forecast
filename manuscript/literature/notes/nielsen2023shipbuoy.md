# Wave Spectrum Estimation Conditioned on Machine Learning-Based Output Using the Wave Buoy Analogy

**Nielsen, U.D., Mittendorf, M., Shao, Y., Storhaug, G. (2023).** *Marine Structures*, 91, 103470.
DOI: 10.1016/j.marstruc.2023.103470.

## Summary
A hybrid ship-as-wave-buoy method estimates the directional wave spectrum from measured ship
motion responses. A physics-based (Bayesian/non-parametric) spectral inversion is conditioned on
integral wave parameters (Hs, Tp, mean direction) separately predicted by a CNN, tested on
~2 years of an in-service container ship's data.

## Relevance to this manuscript
Medium — same domain (directional wave spectrum estimation via ML) but a different task
(ship-response inversion, not buoy time-series forecasting) and a different architecture
(CNN + physics-based inversion, no transformer/sequence model).

## Suggested use
Background/related-work sentence on ML combined with physics-based wave-spectrum estimation, or
as a contrast point ("estimation from ship response" vs. "forecasting from buoy history").
