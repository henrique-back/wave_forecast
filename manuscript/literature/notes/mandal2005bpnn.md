# Ocean Wave Parameters Estimation Using Backpropagation Neural Networks

**Mandal, S., Rao, S., Raju, D.H. (2005).** *Marine Structures*, 18, 301-318.
DOI: 10.1016/j.marstruc.2005.09.002.

## Summary
A small backpropagation NN (Rprop-trained) estimates six scalar bulk wave parameters (Hs, Tz,
Qp, Sp, Emax, Tp) from theoretical Pierson-Moskowitz spectra (wind-speed input) and from
measured Indian-coast spectra, compared against the Scott spectral model.

## Relevance to this manuscript
Low — an early, simple NN application to scalar bulk parameters only; no spectra forecasting,
no deep learning, no directional content.

## Suggested use
At most an optional early-history citation for the "NN applied to wave parameter estimation"
lineage in the Introduction, if a broad historical arc is wanted. Not likely to be cited.
