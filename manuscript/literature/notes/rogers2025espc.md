# Skill of Long-Range Forecasts of Ocean Wave Spectra from the Navy ESPC Version 2 System

**Rogers, W.E., Janiga, M.A. (2025).** Naval Research Laboratory Memorandum Report.
Preprint: arXiv:2510.06484.

**Provenance note:** found during the Track B gap-verification websearch (2026-09-18) while
checking whether any prior work evaluates a wave-spectrum forecast conditioned on wind-sea/swell
partition classification. Citation details come from that search's result snippets, not from
reading the paper directly.

## Summary
A numerical (physics-based) wave-model skill assessment for the Navy's ESPC v2 system, which
stratifies verification by wind-sea fraction, swell height, and wind-sea height — i.e.
partition-conditioned skill scoring, applied to a conventional NWP-coupled wave model.

## Relevance to this manuscript
Medium — the closest match found for "partition-conditioned skill scoring" methodology, but the
forecast system being verified is a numerical wave model, not a machine-learning model. This is
one of the three claims (alongside `meng2023windswell` and `song2023jpo`/`gao2025jgr`-style
target-mismatch cases) that came back with a real partial analog rather than a clean gap — the
manuscript's evaluation-methodology framing should cite this rather than imply the
partition-conditioned evaluation idea itself is unprecedented.
